# Dashboard

The admin dashboard provides a high-level overview of the chapter's membership data.

> ![Admin dashboard screenshot](../images/admin-dashboard.svg)

## Stats Cards

Four summary cards display key metrics:

| Card | Description |
|---|---|
| **Total** | All registered members |
| **Pending** | Members awaiting approval |
| **Approved** | Currently active members |
| **Expired** | Members whose membership has lapsed |

## Charts

### Membership Distribution (Pie Chart)

Shows the proportion of members by status (Approved / Pending / Expired).

### Monthly Registrations (Bar Chart)

Shows the number of new registrations per month for the current year.
