# Announcements

## Announcement Feed

The announcements page displays all chapter updates in a clean, readable feed.

### Members-Only Announcements

Some announcements are marked **Members Only**. These:

- Are hidden from the public landing page
- Are visible only to logged-in members
- Show a small **Members Only** badge

## Reading an Announcement

Click on any announcement to view full details, including:

- Title and content
- Category and date posted
- Author name
- Attached images (clickable to enlarge)

## Categories

Available categories include:

- Events
- News & Updates
- Reminders
- General

Admins can manage categories from the admin panel.
