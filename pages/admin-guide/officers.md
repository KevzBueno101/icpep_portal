# Officers

The officers management page lets you assign and manage chapter officer positions.

> ![Admin officers screenshot](../images/admin-officers.svg)

## Officers Table

Displays all members who hold officer positions:

| Column | Description |
|---|---|
| **Name** | Officer's full name |
| **Position** | Current position (President, Secretary, etc.) |
| **Member ID** | Unique member identifier |
| **Actions** | Edit, Remove Position |

## Creating an Officer

1. Click **Create Officer**
2. Select a member from the member list
3. Choose a position from the available options
4. Submit

## Editing an Officer

Change an officer's position or reassign to another member via the edit button.

## Removing an Officer

Click **Remove Position** to strip an officer's role. The member retains their membership but loses administrative privileges.

## Secretary Delegation

The **Delegation** feature allows the President to grant Secretary-level administrative access:

1. Navigate to the Officers page
2. Click **Secretary Delegation**
3. Toggle delegation on/off for the Secretary

When delegated, the Secretary can:

- Approve/reject membership applications
- Create and manage announcements
- Access the admin dashboard

## Position Restrictions

- Only one **President** can exist at a time
- **FULL_CONTROL** access level is automatically granted to the President
- Positions can only be assigned to members with APPROVED status
